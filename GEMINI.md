# TruckPark Workspace Rules

## Git Workflow & Commit Policy
- **No Unprompted Commits or Pushes**: Never run `git commit`, `git push`, or automatically stage/commit changes unless the user explicitly asks you to do so.
- **Working Tree Preservation**: Keep all code modifications and asset updates uncommitted in the working tree for user review.

## Task Focus & Prompt Priority
- **Focus Strictly on the Current Request**: Always prioritize and execute only what is requested in the user's latest prompt.
- **Do Not Revisit Settled Issues**: Do not re-examine or re-process earlier completed topics (e.g. image pixel adjustments or past subtasks) unless the user explicitly requests a revision.
